# База знаний «ДаРэчы» — конвейер нормативки

Это главный «продукт» команды: качество ответов ассистента упирается не в код, а в качество корпуса.
Работа идёт **параллельно коду, с дня 1, обоими напарниками**. Цель MVP: 25–30 актов категории
«при рождении ребёнка».

## Структура

```
kb_corpus/
├── raw/       # оригиналы актов как скачали с pravo.by (pdf/docx). НЕ редактируем.
├── curated/   # разобранные и проверенные чанки (json) — источник для индексации
└── README.md  # этот файл
```

## Шаг 1. Трекер актов

Общий трекер (Google Sheet) со столбцами:

> № | Акт (название) | Ссылка pravo.by | Реквизиты и дата редакции | Владелец | Статус

Статусы: `скачан → разобран → проверен → проиндексирован`.

Делим 25–30 актов пополам: каждому ~13–15. Список-ядро категории — в плане разработки, раздел 1.

## Шаг 2. Скачать оригинал в `raw/`

Имя файла: `YYYY_N-акта_короткое-имя.pdf` (например `2010_57_posobie-semyam.pdf`).
Скачиваем только с официального источника (pravo.by / НЦЭУ), фиксируем дату редакции.

## Шаг 3. Разобрать в `curated/*.json`

Один акт = один json. Чанк = статья или пункт (не абзац!): retrieval работает по чанкам, и цитата
должна попадать точно в пункт.

```json
{
  "doc": {
    "type": "указ",
    "number": "❗№",
    "date": "❗дата акта",
    "title": "❗полное название",
    "source_url": "https://pravo.by/...",
    "edition_date": "❗дата редакции"
  },
  "chunks": [
    {
      "chunk_id": "❗номер-акта_ст-3_п-2",
      "location": {"article": "статья 3", "point": "пункт 2"},
      "text": "Текст пункта ДОСЛОВНО, без пересказа..."
    }
  ]
}
```

## Шаг 4. Кросс-проверка (обязательно)

Статус «проверен» ставит **второй человек**, сверив чанки с оригиналом.
Правило: одна кривая цитата на демо дороже дня работы — это наша репутация перед жюри.

## Шаг 5. Индексация

`python -m app.kb.ingest` (появится в неделе 2): чанки → эмбеддинги → Qdrant + метаданные → Postgres.
Индексацию запускаем только по чанкам со статусом «проверен».

## Golden set

Параллельно с кураторством каждый добавляет вопросы в `eval/` (формат — `golden_set.example.json`):
30 вопросов к неделе 2, 50 к демо. Три типа: факт-вопросы (суммы, сроки), навигационные,
и 10 заведомо вне базы — на них ассистент **обязан** отказаться.
