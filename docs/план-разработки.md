                     │    честный отказ                 │
                     │                                  │      ┌──────────────┐
                     │ 5. Чек-листы + мини-валидатор    │─────►│ Langfuse     │

**Важно про портал:** контент страниц услуг **генерируется из базы знаний** (каталог услуг в Postgres, собранный из `kb_corpus/curated/`), а не пишется руками. Это и есть аргумент тиражируемости: новая категория услуг = новый корпус актов, без переписывания кода.

Принципы сохраняются: ассистент — информационный слой поверх госсистем, каждый ответ — с цитатой пункта нормативного акта, без источника — отказ, ПДн не храним.

## 4. Портал (новое в v2) — «понятный госу-сайт»

Три типа страниц, и только три — не раздуваем:

1. **Главная**: поиск-вопрос («опишите ситуацию») + сетка «жизненных ситуаций» человеческим языком («Родился ребёнок», «Потерял документы»…). Скелет уже в `frontend/src/App.tsx`.
2. **Жизненная ситуация**: персональный маршрут — какие услуги, в каком порядке, сроки, куда идти.
3. **Услуга**: простыми словами — кому, сколько, в какой срок; чек-лист документов с указанием, где каждый берётся; цитаты нормативных актов; кнопка «спросить ассистента» (контекст страницы передаётся ассистенту!).

Плюс общий компонент — **ассистент-панель** (чат с цитатами + голос), доступный на любой странице, и **киоск-режим** (`?kiosk=1`: крупный шрифт, большие тач-цели, push-to-talk, автоозвучивание) — это канал «для пожилых» и стенд «ноутбук в рамке» из чек-листа заявки.

Анти-цель: не compete с gosuslugi.by по функциям электронного подачи. Наш портал — «понятная витрина + ассистент», подача остаётся на существующих каналах.

## 5. Голосовой ассистент — как именно

### Telegram (голосовые сообщения)
1. aiogram ловит `Voice` (OGG/Opus) → ffmpeg → wav 16 kHz mono.
2. Silero VAD → сегменты → faster-whisper → текст (язык auto: ru/be).
3. Обычный RAG-пайплайн.
4. Ответ: **сначала текст с цитатами** (быстро), параллельно Silero TTS → OGG → голосовое сообщение следом.
5. Латентность: текст ≤ 5 с, голос ≤ 15 с.

### Портал / киоск
1. Push-to-talk кнопка → MediaRecorder (webm/opus) → WebSocket на бэк → тот же конвейер.
2. Ответ стримится текстом (SSE) + аудио TTS.
3. В киоске — USB-микрофон и колонки, автоозвучивание ответов.

### Честные ограничения (проговорить на демо)
- TTS только русский в MVP; текст — ru + be (ключевые ответы), be-голос — этап 2 (fine-tune F5-TTS на Common Voice be).
- be-распознавание голоса приемлемое, не идеальное; для демо-фраз достаточно.

## 6. Скоуп MVP

### MUST (без этого демо нет)
1. RAG с цитатами: ответ = текст + пункт акта + реквизиты документа; нет источника → отказ-шаблон.
2. Telegram-бот: текст + голосовые сообщения (вход и выход).
3. **Портал**: главная с жизненными ситуациями + страницы услуг (контент из базы знаний).
4. **Ассистент на портале**: чат с цитатами + голос (push-to-talk).
5. **Киоск-режим** портала (?kiosk=1).
6. Роутер услуг: свободная фраза → 2–3 уточняющих вопроса → маршрут из 3–4 услуг.
7. Чек-листы по услугам + мини-валидатор комплектности (rule-based).
8. Корпус: 25–30 актов категории.
9. Langfuse-трейсинг + счётчики.

### SHOULD (если неделя 3 идёт ровно)
- Беть в ключевых ответах + переключатель RU/BE.
- Golden set 50 вопросов с автопрогоном.
- Видео-демо 60–90 с (страховка живого демо).

### WON'T (осознанно режем — «этап 2»)
- Полное заполнение заявлений (остаётся проверка комплектности).
- Запись на приём / напоминания.
- Интеграции с госбэкендами — их нет по архитектуре.
- Белорусский TTS-голос.
- Хранение ПДн.

## 7. База знаний — конвейер (ваша совместная «тяжёлая работа»)

Подробно — в [kb_corpus/README.md](../../kb_corpus/README.md). Суть:

1. **Трекер актов** (Google Sheet): акт, ссылка pravo.by, реквизиты/редакция, статус, владелец. 25–30 позиций, пополам.
2. Скачивание оригиналов в `kb_corpus/raw/`.
3. Парсинг (код твой, ~2 дня): docling/pdfplumber → структурные чанки по статьям/пунктам с метаданными в `kb_corpus/curated/*.json`.
4. **Кросс-проверка 100% чанков вторым человеком** — обязательный шаг.
5. Индексация: e5 → Qdrant + Postgres (запуск только по «проверенным»).
6. **Golden set**: 30 вопросов к неделе 2, 50 к демо (формат — `eval/golden_set.example.json`). Регресс каждую неделю. Цели к демо: ≥90% ответов с корректной цитатой, 100% отказов на out-of-scope.
