# Брендбук ДаРэчы

Знак — `frontend/public/logo.svg`. Палитра сайта берётся из него.

## Знак

Стеклянный лист с загнутым углом и слово Darechy. Это ответ по документу. В шапке только этот файл, без второго названия рядом.

## Цвет

| Роль | HEX | Токен |
|---|---|---|
| Фон | `#F2F4FA` | `--bg` |
| Карточка | `#FFFFFF` | `--surface` |
| Текст | `#233883` | `--ink` |
| Действие | `#2563EB` → `#5A4BF2` | `--primary`, `--mark` |
| Готово | `#1C4A3A` | `--ok` |

Кнопки — тот же градиент, что в знаке. Страницу им не заливаем.

## Беларусь

Под шапкой — линия 1 px красная `#C8102E` и 2 px зелёная `#1C4A3A`. Язык RU/БЕЛ остаётся. Ромб в логотипе не используем.

## Форма

Радиус 2 px. Без мягких теней и без «пилюль». Киоск: одна кнопка голоса, плитки тем, язык слева.
